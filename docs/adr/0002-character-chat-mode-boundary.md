# Separate script and free conversation modes

V1.1 distinguishes two user-facing modes for the same selected character: Script Mode applies the selected script's world and plot constraints, while Free Conversation Mode preserves the character's identity, personality, and speaking style without requiring plot progression. The two modes must keep chat history and plot context separate, while user preferred name, relationship state, and non-plot user information may remain continuous; this preserves character continuity without turning the product into a generic AI chat service.
