# 项目非运行资产

本目录存放不会进入微信主包的源素材和参考素材。运行图片只放在
`apps/miniapp/src/assets/`，不要把这里的文件直接引入小程序页面。

## 目录

| 目录 | 内容 | 使用边界 |
|---|---|---|
| `brand-assets/` | 月满楼 Logo 矢量源文件、导出位图和说明 | 选取运行文件后复制到 `apps/miniapp/src/assets/logo/` |
| `reference/流氓叙事/` | 《流氓叙事》角色海报、剧本封面、测评截图和参考图 | 仅作母版、调研和重新裁切来源 |
| `reference/芸芸素材/` | 《芸芸》主视觉、角色海报和未接入的剧情图 | 仅作母版、调研和后续按需接入 |

## 规则

- 本目录内容不参与 Taro 构建，不属于微信主包。
- `reference/` 是本地参考素材，已由 `.gitignore` 排除；干净克隆不会包含这些文件。
- 正式运行图片必须复制并压缩到 `apps/miniapp/src/assets/`，再更新那里的资产索引。
- 公开网络素材可能受版权限制；未确认授权前不得提交、分发或用于商业发布。
- 删除母版前先确认对应运行图已生成、验收且无需重新裁切。
