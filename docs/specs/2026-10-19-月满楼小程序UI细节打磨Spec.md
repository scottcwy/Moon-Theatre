## 1. 目标

在不改变 H5 视觉方向、生产路由和业务契约的前提下，修掉生产页面的浮层遮挡、深色主题残留、假数据/假状态、触控尺寸和资源精度问题。

判断标准：在 375×812、390×844、DPR2/DPR3、带/不带 home indicator 的设备上，页面无不可读文字、无浮层压字、无死控件；所有状态值都有真实数据来源或明确空态。

本 Spec 是 `2026-10-01-H5视觉到Taro生产前端-多Agent实施冻结Spec.md` 的生产端细节补充。第二份合同 Spec 覆盖的帧以新 Spec 为视觉权威；其余帧仍以 H5 Spec 为准。

## 2. 范围与边界

### 2.1 范围内

- `apps/miniapp/src/pages/` 下已上线的 H5 舞台页、列表页、详情页、登录页和分享预览页。
- `packages/miniapp-ui/src/` 下的 tabbar、状态卡、聊天行、角色详情 hero、分享卡、按钮和角标。
- `apps/miniapp/src/app.config.ts`、各页面 `definePageConfig`。
- `apps/miniapp/src/assets/` 与 `assets/design/manifest.json` 的 UI chrome 资源。

### 2.2 非目标

- 不重做 H5 13 帧，不修改 `playground/`、`design-frames.json`、`PilotFrame`。
- 不修改 API、数据库、认证、点数、支付、聊天协议和业务状态机。
- 不新增页面或路由；设置页、真实在线状态字段另行开 Spec。
- 不引入新字体、CDN、远程图片或新的视觉方向。
- 不把 13 帧视觉门禁的环境问题混进本 Spec 的结论；该门禁单独复验。

## 3. 修复前基线与关键数字

- tabbar 本体 `106rpx`，底部偏移 `12rpx + safe-area × 0.5`；选中态装饰 `149×123rpx`，向上溢出 `17rpx`。
- 375pt 下 tab item 实际宽度约 `143.5rpx`，选中态比 item 宽约 `5.5rpx`（约 `2.75px`）。
- 现有底部避让：首页 `124rpx`、个人页 `132rpx`、社区 `160rpx`、聊天列表 `220rpx`、`PageShell tabBarReserve` `320rpx`；tabbar 视觉高度约 `135rpx + safe area`。
- 聊天列表背景在 `0–34%` 只叠 `6%` 暗色，行名 `#211A1C`、时间 `rgba(90,74,78,.58)`。
- 个人页成长卡底色 `rgba(240,228,214,.94)`，标题 `#fff7ed`。
- UI chrome 资源：`tab-selected.png` 149×123、`tab-surface.png` 684×106、`title-calligraphy.png` 680×338、`courtyard.jpg` 750×1124、`hakuzo.jpg` 600×600。

## 4. 决策冻结

| 编号 | 决策 |
| --- | --- |
| D1 | 保留浮起式 tabbar 和 123rpx 选中态；通过单一 reserve token 和几何修正解决压字，不改成贴底平栏；不在 bar 上方加可见灰条。 |
| D2 | 选中态胶囊宽度不得超过 tab item 宽度；图标/文字在胶囊内视觉居中，垂直偏差不超过 `2rpx`。 |
| D3 | 登录页、个人页、分享预览使用 custom navigation；个人页只保留页面内一个标题。 |
| D4 | `StatusStateCard` 增加暗色 tone；聊天页所有状态卡统一使用暗色。 |
| D5 | 角色图必须数据驱动；生产页面 SCSS 不得硬编码具体角色图片。 |
| D6 | 无真实数据时不渲染假状态：在线 badge 删除，points 为 null 显示 `点数 —`。 |
| D7 | “立即分享”必须打开微信分享图片菜单；不可用时降级为保存并改文案，不能两个按钮同一行为。 |
| D8 | 首页齿轮在没有设置页之前删除；不得保留无响应 affordance。 |
| D9 | 所有可交互元素命中区不小于 `88rpx`（44px）；视觉尺寸可小于命中区。 |
| D10 | UI chrome（tabbar、选中态、书法标题）使用 3x 或矢量；照片至少 2x；照片放大不得超过 1.1x。 |
| D11 | 非 tab 页不得预留 tabbar 高度；只有实际渲染 StageTabBar 的页面才消费 tabbar reserve。 |
| D12 | 未读点使用错误色/珊瑚色 + 深色描边，锚定图标右上角；交互图标改用 `Icon` 或资产，不用裸 Unicode。 |

### 8.2 手工场景

1. 聊天列表：登录态，0/1/10/50 行会话，含未读和长预览；分别检查顶部、中部、底部。

3. 点数：loading、null、真实值三种状态，确认不出现假 0。
4. 分享预览：模拟分享菜单可用/不可用；568pt 短屏和 812pt 常规屏。
5. 登录页：阻断标题图片加载，确认仍有可读标题。
6. tabbar：选中/未选中/未读点；375×812 和 390×844。
7. 聊天输入：键盘弹起、Android env=0、placeholder 可读。
8. 个人页：成长记录标题、已登录/未登录/loading 三态、无双层标题。
9. 记忆页：底部无多余 tabbar 空白。
10. DPR3 设备或 3x 模拟器：tabbar 边缘、选中态、书法标题不糊。
