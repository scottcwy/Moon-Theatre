## 4. 支付 UI-only 边界

### 4.1 生产接线（选 B）

- 生产 `quota/buy`：保留真实 `GET /api/quota/packages`、`GET /api/quota/balance`；改为 custom navigation（标题“我的”+ 返回键）；套餐列表换新视觉；点底部“确认支付”先打开 `PaymentConfirmSheet`，sheet 内“确认支付”再调用现有 `handlePay`；“暂不支付”只关闭 sheet。

## 12. 变更规则

- 新增帧、改变替换关系、改支付边界、改 QR 契约或改基线转换规则，必须先更新本 Spec。
- 支付 UI 一旦需要真实支付动作、订单写入或新数据字段，必须另开支付 Spec。
- 支付 UI-only 帧只能标 `IMPLEMENTED / UI_ONLY`；8/9 整屏视觉只能标 `BLOCKED` 直到干净导出。
- 旧 13 帧矩阵、baseline 和 `approved-masks.json` 不得被本轮改动覆盖。
