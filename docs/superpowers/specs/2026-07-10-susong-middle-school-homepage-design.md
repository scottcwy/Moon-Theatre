# 宿松中学官网宣传页设计

## 目标

制作一个可在本地浏览器直接打开的单文件 HTML 宣传页，忠实复刻安徽省宿松中学官网的传统校园门户风格，不接入现有小程序或服务端代码。

## 交付范围

- 最终交付一个自包含 HTML 文件。
- CSS 和少量交互 JavaScript 均内嵌在 HTML 中。
- 不安装依赖，不引入构建流程，不请求业务接口。
- 页面内容用于视觉展示，栏目链接不进入真实业务页面。

## 页面结构

1. 顶部校训、校名标识和深蓝色横向导航。
2. 校园主题横幅，带传统轮播序号和左右切换按钮。
3. 日期、检索框和快捷入口组成的工具条。
4. 图文荐读、动态关注、通知公示和单位概况组成的首屏内容区。
5. 校园资讯、招考信息、教育时事、教学教研等密集新闻栏目。
6. 图说宿中图片区和传统蓝色页脚。

## 视觉约束

- 采用约 1200 至 1300 像素的传统定宽门户布局。
- 主色为深蓝、亮蓝、白色，标题和重点信息使用少量红色。
- 使用细边框、小字号、高信息密度和紧凑间距，保留老式校园官网气质。
- 页面图片以内嵌 SVG 数据或 CSS 图形表达，确保单文件离线打开时不出现空白资源。

## 交互与验证

- 轮播按钮和序号可以切换横幅内容。
- 搜索框提交后在页面内显示检索提示，不发起网络请求。
- 在本地静态服务器中检查桌面端和窄屏布局、控制台错误、图片显示和文字溢出。
- 最终在 Codex 本地内置浏览器中打开页面供用户查看。
