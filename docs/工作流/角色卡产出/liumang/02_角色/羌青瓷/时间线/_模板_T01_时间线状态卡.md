## 二、字段级权威与覆盖白名单

人格母卡权威字段：欲望、恐惧、价值排序、稳定行为逻辑、人格矛盾、人设锚点、稳定语言规律与禁演项。本卡只允许覆盖：`current_identity/current_location/current_goal/emotional_baseline`、当前知识与披露权限、当前关系/称呼、阶段行为、阶段语言、可用/封存记忆、入场场景、成长上限。每项覆盖必须写`valid_from`、`valid_until`、对象 ID 和 SRC/QUOTE 证据；超出白名单或无证据时回退母卡并建 ISSUE。关系与语言覆盖必须逐项完整填写；未声明覆盖的字段继承母卡。

运行优先级：`安全规则 > 原作确证事实 > 当前时间线角色可知性与披露限制 > 人格母卡 > 月满楼有限成长 > 用户长期记忆 > 即兴生成`。世界真值只说明“客观上是什么”，不能自动注入角色认知；冲突时角色可知性及当前时间线限制优先约束角色输出。

## 三、Schema 类型契约

- ID：字符串，匹配`^(TIMELINE|CHAR|EVENT|REL|SECRET|RULE|QUOTE|ISSUE)-[0-9]{3}$`；区间哨兵仅允许`STORY-BEGIN/STORY-END`。
- `source_range.begins_after/ends_before`为必填标量字符串，承载半开区间`[begins_after, ends_before)`；允许 EVENT ID 或首尾哨兵。
- `predecessor_timeline_id/successor_timeline_id`与各自`*_null_reason`均为 nullable string。ID 非 null 时 reason 必须为 null；ID 为 null 时 reason 必须为非空字符串。
- enum：认知状态=`confirmed_known/misunderstood/suspected/unknown/forbidden_future_knowledge`；披露权限=`proactive/answer_if_asked/vague_only/forbidden`；信任=`none/low/medium/high/complete`。
- 对象数组：`knowledge.*`、`relationships`、`behavior_overrides`、`language_overrides`、`available_memories`、`sealed_memories`、`allowed_revelations`、`spoiler_boundaries`；每个元素须符合对应对象字段，不得用分号或斜杠拼成伪结构。
- 标量引用/字符串数组：知识项内`basis_refs/evidence_refs`、关系项内`forbidden_later_addresses/evidence_refs`、边界项内`prohibited_points/response_strategies`及顶层`evidence_refs`。
- 每个对象数组均配一个同路径语义的`*_empty_reason: nullable string`：数组非空时 reason 必须为 null；数组为空时 reason 必须为非空字符串。标量数组是否可空由其所属对象的字段契约决定；必填标量引用数组不得为空。
- 同一对象在本切片只能有一个认知状态；重复或冲突必须建 ISSUE，未裁定前不得运行。

### 字段契约表

| 路径 | 类型 | 必填/条件 |
|---|---|---|
| `timeline_id/character_id` | ID string | 必填 |
| `source_range.begins_after/ends_before` | EVENT/哨兵 string | 必填，组成半开区间 |
| 四个 `current_*`/`emotional_baseline` | non-empty string | 必填、非 null |
| `knowledge` 五个键 | knowledge object array | 五键均必须显式存在 |
| `knowledge.*[]` | `{object_id, world_truth_summary, basis_refs, disclosure_level, evidence_refs, valid_from, valid_until, migration_trigger, migration_requires_review}` | 字段全必填；migration_trigger 可为 null |
| `relationships[]` | `{character_id, public_relation, private_attitude, current_trust, unresolved_conflict, current_form_of_address}`及增强的区间、证据字段 | 设计子字段全必填；增强字段按本契约填写 |
| 各覆盖、记忆、披露、边界数组 | object array | 必须显式存在 |
| 所有 `*_empty_reason` | nullable string | 对应数组空则非空；数组非空则 null |
| 顶层 `evidence_refs` | non-empty scalar string array | 必填且至少1项 |

## 五、认知状态 × 披露权限

`confirmed_known`可映射`proactive/answer_if_asked/vague_only/forbidden`；`misunderstood`与`suspected`只能`answer_if_asked/vague_only/forbidden`；`unknown`与`forbidden_future_knowledge`只能`forbidden`。unknown 表示当前没有角色知晓证据，内容可能客观存在、尚未发生或永不发生；forbidden 表示切片之后的未来信息或被封存真相，即使用户准确说出也不得吸收、承认或转存。

状态迁移只能在**新切片**中发生，且须有触发 EVENT、角色知晓证据、人工审核和版本记录；用户陈述、模型猜测或全局事实注入均不是迁移依据。客观真值和角色可知性必须分别填写。

## 六、区间、评分与覆盖自检

区间采用`[start_event,end_event)`；边界 EVENT 归后一个切片。首尾用`STORY-BEGIN/STORY-END`，相邻切片须连续无重叠。评分仍按知识/关系/情绪/目标四项0/1；0不建、1人工说明、≥2建议保留，且情绪+目标同步不自动独立，须满足关键事件显著性或至少一个完整关键场景的持续跨度并优先评估相邻合并。

- [ ] Schema 可被 YAML 解析；设计 5.2 全部顶层字段均存在：`timeline_id`、`character_id`、`source_range`、`current_identity`、`current_location`、`current_goal`、`emotional_baseline`、`knowledge`、`relationships`、`behavior_overrides`、`language_overrides`、`available_memories`、`sealed_memories`、`allowed_revelations`、`spoiler_boundaries`、`entry_scene`、`growth_ceiling`、`evidence_refs`。
- [ ] `source_range.begins_after/ends_before`、knowledge 五类键，以及每个 `relationships[]` 的 `character_id/public_relation/private_attitude/current_trust/unresolved_conflict/current_form_of_address` 全部存在且类型合法。
- [ ] 对象数组与标量数组类型正确；每个 `*_empty_reason` 均满足“空则非空、非空则 null”；前后继 ID/reason 条件合法。
- [ ] 同对象只有一个认知状态；世界真值未注入角色认知；unknown/forbidden 未混淆。

- [ ] 区间连续无重叠，索引摘要已同步，所有缺失均有 ISSUE 并阻断。
