## 说明

- 12 本角色本、组织者手册、2 份 encrypt PDF 为扫描件，用 macOS Vision OCR（zh-Hans）转写为清洗文本。清洗文本为工作底稿，暂存 `/tmp/yunyun_extract/ocr/`（106 个文件，约 1.3MB，未入库）；正式归档时再决定是否收入 `00_输入清单/清洗文本/`。下方“清洗后文本”列仅写文件名，实际前缀为 `/tmp/yunyun_extract/ocr/`。
- OCR 清洗文本按原 PDF 物理页切分并保留页标记 `===== PAGE N =====`；原文件显示页以页脚数字为准（抽样核对：物理页 3 页脚为 `-3-`，偏移量 0）。个别页存在 OCR 错字，引用事实时必须回原图核对（ISSUE-004）。
- 线索卡 JPG 每张一个清洗文本，命名保留原卡片名；卡片材料偏移量填“不适用”。
- 音频（SRC-016）未转写；海报/道具 JPG（SRC-035/036）为视觉素材，不进入文本映射。
