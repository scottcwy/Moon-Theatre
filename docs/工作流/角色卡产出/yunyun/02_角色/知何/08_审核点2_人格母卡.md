## 一、实例化与判定规则

1. 被审核产物只有本次真实的“人格母卡”和“原作语言样本库”，进入本审核点时均须为“待审核”；公共规范、审核点 1 及事实库属于有效性依赖，不得误标为本次“待审核”。
2. 本文件是空白模板，括号占位和 `未填写（实例化阻断）` 必须在实例化时替换。实例化后，模板链接不得冒充真实产物链接；空值填 `不适用＋理由`，应有但未取得的内容填 `待补充＋ISSUE-###`，不得留空。“不得留空”仅约束实例，不要求空白模板预造真实数据。
3. 每项当前判定只能为 `通过/局部修正/阻断`。首次判为局部修正或阻断必须建立 ISSUE；整改、责任、证据、复核和关闭信息只在“ISSUE 权威详情”维护。
4. 每个争议项的处置动作只能为：`保留确证/降级推断/标记存疑/删除/人工创作决定`。不得使用“暂时保留”“优化措辞”等替代动作；`人工创作决定` 必须明确标记为月满楼扩展，不能冒充原作人格。
5. 唯一机械汇总：任一阻断 ISSUE 未关闭、失败演练未通过或门禁未满足，结论为“阻断”；否则任一 ISSUE 未关闭或任一维度为“局部修正”，结论为“局部修正”；否则十一项全部通过且 ISSUE 全部合规关闭，结论为“通过”。
6. 任何未关闭 ISSUE 均不得签署通过。阻断 ISSUE 不得以接受风险关闭；ISSUE 复核关闭后必须把关联项“当前判定”更新为“通过”，并在原判审计保留原判、日期、审核人和 ISSUE ID，不得覆盖。
7. 以下均为非法组合：当前判定为局部修正/阻断但关联 ISSUE 已关闭且未更新为通过；局部修正/阻断未关联 ISSUE；ISSUE 未反向关联审核序号/门禁；主表、详情、ISSUE 索引与权威详情状态不一致；计数不合计。发现任一非法组合即视为表单错误，建立新的阻断 ISSUE，在修正前机械汇总只能为“阻断”。
